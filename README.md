# 点滴工具面板交互 Demo

## 本地预览

在本目录的上一级执行：

```bash
python3 -m http.server 4173 --directory tool-panel-demo
```

然后打开：<http://127.0.0.1:4173/>

如果从本项目工作区根目录启动：

```bash
python3 -m http.server 4173 --directory outputs/tool-panel-demo
```

## 交互

- 面板收起时，可用手指上下滑动、鼠标滚轮或鼠标按住拖动浏览记录内容；滚动内容会自然进入面板下方，不在面板顶部硬裁切。
- 在工具面板内向上拖动：内容按拖动比例从当前记录滚向最新记录；未达阈值松手会连贯返回原记录，达到阈值后继续展开并定位最新记录；单击面板或把手不会展开。
- 展开后点击上方记录内容：收起工具面板。
- 展开后在上方内容区向下拖动：面板跟手收起；短距离拖动会恢复展开。
- 展开状态下，记录内容区的滚动和卡片点击被透明交互层拦截。

## 设计基准

- 页面逻辑尺寸：402×874。
- `assets/` 中全部 PNG 均保留用户提供的 2× 原始分辨率，并按逻辑尺寸显示。
- `reference-collapsed.png`、`reference-expanded.png` 是 Figma 两个端点的 402×874 参考图。
- `preview-2x.png` 是 Demo 收起态的 804×1748 二倍预览图。
